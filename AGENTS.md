## How to Update
1. Edit `index.html`
2. Commit changes: `git add . && git commit -m "description"`
3. Push to both repositories:
   - Backup: `git push origin main`
   - GitHub Pages: `git push pages main`
4. GitHub Pages auto-deploys within 1-2 minutes from `vazden-creator.github.io`
